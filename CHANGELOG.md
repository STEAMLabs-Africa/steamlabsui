# Changelog

## Unreleased

## 1.0.0

- Renamed the package from `@steamlabs/ui` to `steamlabsui`.
- Added the components found across the STEAMLabs repos (see `docs/INVENTORY.md`): `Icon`, `Section`, `SectionHeader`, `PageHeader`, `Separator`, `TextLink`, `BackLink`, `Menu`, `SegmentedControl`, `Select`, `Checkbox`, `RadioGroup`, `Switch`, `Avatar`, `AvatarGroup`, `CodedCard`, `Stat`, `Table`, `List`, `ListItem`, `Tile`, `TileGrid`, `Progress`, `ProgressRing`, `Steps`, `Accordion`, `Tabs`, `Breadcrumb`, `Pagination`, `SkipLink`, `Alert`, `EmptyState`, `Spinner`, `Skeleton`, `ToastProvider` and `useToast`, `Dialog`, `Tooltip`, `Reveal`, `CountUp`.
- `Button` gains `loading`; `Badge` gains the `neutral` variant and `dot`; `Field` gains `required`.
- Added the `--subtle` neutral token for hover rows, tracks and skeletons.
- Added the ReadMe-style docs site (`bun run docs`), the `bun run new` component scaffold and the release workflow.

## 0.1.0

- First version: tokens, CSS, brand layer, Tailwind theme, `Button`, `Badge`, `Pill`, `Card`, `Input`, `Textarea`, `Label`, `Field`, `Eyebrow`, `Heading`, `Lead`, `Band`, `Container`, `ThemeProvider`, `Logo`.
